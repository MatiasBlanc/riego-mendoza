# Riego Mendoza - Landing Page

Landing page profesional para **Riego Mendoza**, empresa de sistemas de riego automatizado e hidroponía en Mendoza, Argentina.

## 🚀 Stack Tecnológico

- **React** - Framework de UI
- **Vite** - Build tool y dev server
- **Tailwind CSS** - Framework de estilos
- **Lucide React** - Iconos SVG
- **React Icons** - Iconos de FontAwesome

## 📁 Estructura del Proyecto

```
src/
├── components/
│   ├── ui/              # Componentes UI reutilizables
│   │   ├── ServiceCard.jsx
│   │   └── StatItem.jsx
│   ├── Footer.jsx
│   ├── Hero.jsx
│   ├── HeroImageCarousel.jsx
│   ├── Navbar.jsx
│   ├── Servicios.jsx
│   ├── SobreMi.jsx
│   ├── Stats.jsx
│   └── WhatsAppButton.jsx
├── data/
│   └── servicios.json   # Datos de servicios
├── hooks/
│   └── useInView.js     # Hook para animaciones scroll
├── App.jsx
├── index.css            # Estilos globales y animaciones
└── main.jsx
```

## 🛠️ Desarrollo

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Build para producción
npm run build

# Preview del build
npm run preview
```
